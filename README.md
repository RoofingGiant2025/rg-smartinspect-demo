# Roofing Giant SmartInspect — Public Read-Only Demo

A public, no-login demonstration of the SmartInspect user experience using **entirely fictional and synthetic data**.

- No accounts, passwords, emailed one-time codes, forms, uploads, databases, cookies, third-party JS, network requests, or customer records.
- Interactive, client-side inspection checkpoint explorer, two sample properties, unpriced example scope, manufacturer review examples, and QA education.
- All sample quantities, inspection results, and evidence identifiers are **fictional** and never represent a performed inspection.
- The public repo/site is intentionally isolated from CentralBlock, Roofing Giant CRM, SmartInspect protected pilot, Dropbox, and manufacturer source files.
- There are **no** real roof installation diagrams; withheld technical assemblies are displayed only as warnings.
- The official protected pilot and its own Cloudflare/email sign-in remain unchanged. This public experience exists because visitors requested no password and no email-code barrier to *view* a demonstration.
- This is **not** a live CRM, quoting or customer publishing system.

## Security and operational boundaries

This is a static GitHub Pages website: no server-side app, secrets, tokens, routes to CRM APIs, or write operations. Do not add real job data or authorization actions to this repository. If real customer data is ever needed, use the existing protected authenticated CRM.

The single index.html file includes all client code.
